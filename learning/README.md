Это модель которая учится умножать! (в данном коде она учится умножать на 2)
    Что бы научить ее умножать на другие числа (например: 3, 10, 25):
        1. В tensor.py вы можете указать свои данные (например csv таблицу с двумя столбцами x и y)
        2. В стоблце "х" могут быть числа: (3, 5, 7, 8), а в "y" числа: (9, 15, 21, 24) - если хотите научить модель умножать на 3
        3. Идеальный результат обучения модель (при умножении на 3) должен выглядеть вот так:
            Weight: 3
            Bias: 0
        4. В main.py вы запускаете обучение
        5. Так же в main.py можно поиграть со значением learn() - на 9 строке. Это кол-во циклов обучения
